# WhatsApp Bot - Enhanced Features

This document provides information about the enhanced WhatsApp bot.

## 🎉 What's New in v2.0

✅ Command organization with modular structure
✅ 5+ fun commands (jokes, quotes, facts, dice, coin)
✅ Admin-only commands for management
✅ Group management with welcome messages
✅ Better error handling and logging
✅ Utility commands (help, time, stats)
✅ Broadcast messaging system

## 📦 Command Files

- **commandHandler.js** - Routes all commands
- **basicCommands.js** - Basic functionality
- **funCommands.js** - Entertainment features
- **utilityCommands.js** - Utility functions
- **adminCommands.js** - Admin-only features

## 🔧 Configuration

Edit `src/index.js` to:
1. Add your admin numbers
2. Customize admin list
3. Configure admin privileges
